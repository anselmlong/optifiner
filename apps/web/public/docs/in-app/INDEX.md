3. Replace `[Add your content here]` with your specific information

## Integration

Once you customize these files, they can be displayed in the Help page using a documentation viewer component. The structure is designed to be:

- **Simple** - Plain markdown format easy to edit
- **Consistent** - All files follow the same template
- **Modular** - Each file is independent and self-contained
- **Extensible** - Easy to add new sections

## Tips for Writing Documentation

- **Be clear and concise** - Use simple language
- **Include examples** - Show, don't just tell
- **Add screenshots/diagrams** - Helpful for UI guides
- **Use bullet points** - Easy to scan
- **Link between docs** - Help users navigate
- **Keep it current** - Update regularly
