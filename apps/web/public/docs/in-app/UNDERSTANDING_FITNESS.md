# Understanding Fitness

Fitness functions are the mathematical formulas that measure how "good" your code is. Borrowed from evolutionary biology and genetic algorithms, fitness functions work just like natural selection: just as nature favors organisms best adapted to their environment, Optifiner uses fitness functions to identify which code changes actually make your program better. Think of it as a report card for your code—it takes multiple performance metrics and combines them into a single score that tells us whether a proposed change is an improvement or not.

Optifiner automatically determines benchmarks for your code and calculates what can be optimized to improve these benchmarks. This means you don't need to manually specify every metric or weight—the system intelligently identifies the opportunities for improvement and directs agents toward changes that will meaningfully enhance your code's fitness score.
